# 19 — 错误 / 中断 / 回放清洗

**What to build:** 让失败有形状。流开始之前就失败的情况（未登录、身份与请求不匹配、没有可用的 Key 且系统回退关闭）仍然走普通 HTTP 错误，不会出现半个流；流开始之后失败则先发一条错误事件（稳定错误码 + 一句可读文案），再以收尾事件结束这一轮。用户看到的错误提示是独立于教练正文的提示单元，绝不混进气泡，也不会被语音朗读念出来。

用户主动中断不算错误：不弹提示、不播报、不为该轮落库助手消息，只在服务端留一条告警。传输中途断开（收尾帧之前连接结束）收敛到「连接中断」这个确定终态，保留已收到的正文，不留下永远转圈的空气泡。最后一并处理回放：历史接口返回的是清洗后的文本，旧数据里的结构残留不会再被演一遍。

**Blocked by:** 17 陪练协议帧 + 服务端清洗 + 前端协议层

**Status:** ready-for-agent

- [ ] AC1：流中供应商失败时，响应里出现错误事件（错误码与可读文案）并以收尾帧结束且收尾原因为错误；气泡正文中不出现该错误文案，错误文案也不以正文增量帧发出。
- [ ] AC2：已产生部分正文后失败时，已显示的正文保留，错误以独立的提示单元追加显示（不与正文混排），且该提示不进入语音朗读。
- [ ] AC3：用户主动中断后，界面不出现错误提示、不触发朗读，后端不为该轮落库助手消息，服务端记录一条告警级事件。
- [ ] AC4：收尾帧之前连接中断时，界面保留已收到的正文并标注「连接中断」，终态为截断，不出现永远显示「正在思考」的气泡。
- [ ] AC5：流开始前的失败不产生任何事件帧：未认证返回 401、身份与请求不匹配返回 403、无可用 Key 返回 409 语义错误，响应体是普通 JSON 错误而非事件流。
- [ ] AC6：写入一条含 JSON 外壳或代码围栏的助手历史记录后，历史接口返回清洗后的文本，页面上不再出现此前泄漏过的结构内容。
