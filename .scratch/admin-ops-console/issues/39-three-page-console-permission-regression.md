# 39 — 三页工作台 + 权限回归

**What to build:** 后台从单页展示变成可用的三页工作台：数据概览、用户列表、用户详情，侧边栏两个入口，三条路由都能直达与刷新。列表页的搜索、筛选、排序、页码全部写进 URL，可分享、可后退、刷新不丢；从列表进详情再返回，原来的筛选结果还在。最后补一遍权限回归：管理端的每一个端点对非管理员都必须 403、未登录必须 401，前端也把非管理员挡在门外。

**Blocked by:** 36 用户列表搜索 / 筛选 / flags

**Status:** ready-for-agent

- [ ] AC1 侧边栏有「数据概览」与「用户」两个入口，当前项随路径高亮；概览、列表、详情三条路由可直接输入地址访问并可刷新（刷新后仍渲染对应页面，不出现重定向到首页或空白）。
- [ ] AC2 列表页的搜索词、筛选、排序、页码都体现在 URL 查询串中；复制该 URL 到新标签打开、或刷新、或浏览器后退，页面渲染结果与请求参数与原来一致。
- [ ] AC3 搜索输入在停止输入约 300 毫秒后只发出一次请求（用请求替身断言调用次数与最后一次参数）；筛选面板可一键清空并回到默认查询，清空后 URL 与请求都回到默认。
- [ ] AC4 从列表点某个用户进入详情，再点返回，回到的是原来的筛选结果列表（URL 与列表内容一致，状态不丢）。
- [ ] AC5 详情页各分区独立呈现加载中、空态与错误态：让某一个分区接口失败时，其他分区仍正常渲染（用替身制造该失败并断言其余分区可见）。
- [ ] AC6 权限回归全绿：非管理员访问任一管理端路由被重定向回用户端；所有管理端点（概览、列表、详情、导出、审计查询）对非管理员均返回 403、未登录均返回 401，逐端点各一条用例。
