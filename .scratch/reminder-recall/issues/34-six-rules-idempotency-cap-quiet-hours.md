# 34 — 六条规则 + 幂等 / 上限 / 免打扰

**What to build:** 在已有调度宿主之上补六条提醒规则：训练日的每日训练提醒、休息日的恢复日提醒、按 3/7/14 天阶梯降频的连续未训练召回、周目标达成提醒、周期末缺口提醒、以及无计划新用户的引导提醒。同一天命中多条时按优先级裁剪并遵守每日上限与免打扰时段；被判为「不该发」的候选也要留下可查的跳过记录，这样运营能回答「这个人今天为什么没收到」。用户可在设置里逐类开关，非法偏好被拒绝。

**Blocked by:** 33 提醒调度宿主 + 投递记录 + 收件箱

**Status:** ready-for-agent

- [ ] AC1 训练日且当天未打卡时，tick 后产生一条每日训练提醒，正文含今日训练重点与预计时长并带可跳转目标；当天已打卡时 tick 不再产生该提醒。
- [ ] AC2 连续未训练召回按阶梯生效：距上次打卡 3 天产生召回、6 天不产生、7 天再次产生；超过 14 天后降为每 7 天最多一次，不出现每天都催的情况。
- [ ] AC3 周目标相关提醒各最多一次：本周完成次数达到目标当天产生一条达成提醒；周期末仍有缺口时产生一条含「还差几次」的缺口提醒；同一周期内重复 tick 不重复产生。
- [ ] AC4 免打扰时段生效：落在时段内、仍在当日有效窗口内的候选被顺延到时段结束后发出；已超出当日窗口的候选记为跳过且不跨日补发（用户可见通知数量与投递记录状态可同时断言）。
- [ ] AC5 每日上限生效：同日命中三条候选且上限为 2 时，用户只看到 2 条提醒，被裁掉的候选留下可查询的跳过记录（含原因），不静默丢弃。
- [ ] AC6 用户关闭某一类提醒后该类不再产生（其他类不受影响）；提交非法偏好（免打扰开始与结束相同、每日上限越界）返回 4xx 并保持已存偏好不变。
