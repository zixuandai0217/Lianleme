# 44 — 评分→视觉映射 + 2D 降级

**What to build:** 把体型分析的各部位评分翻译成「用户看到的样子」：每个肌肉区域的发光强度与颜色、未评估区域怎么表达、图例文案、两次分析的差异徽标，以及设备不支持 3D 时该显示什么。这一层是纯逻辑，不需要浏览器也能验证，它决定了热力图「亮暗是否正确」。别名与自由键的归并也在这里收口，模型漏项是常态而不是异常。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] AC1：映射沿用 ADR-0005：0 分 → 发光强度 0、色相 0（暗红）；10 分 → 强度 1、色相 60（亮黄）；中间值单调不跳变（表驱动断言）。
- [ ] AC2：脏数据健壮：负数、>10、NaN、字符串、null 被钳制或忽略，函数不抛异常且不产生负强度或超范围色相。
- [ ] AC3：区域归一化：别名（核心/腹/侧腹）归并到 `abs` 并取平均；成对区域左右分侧取平均，差 ≥3 分产出「单侧偏差」标注；无法归一的键不进入 3D 参数但保留在列表数据里。
- [ ] AC4：未评估语义：缺失区域产出中性低强度 + 「未评估」图例项，不参与任何平均、不被当作 0 分（把缺失当 0 的实现应让测试失败）。
- [ ] AC5：对比差异：两次记录同一区域 |Δ|≥2 才产徽标且升降方向正确；两侧都未评估不产徽标；变化 top-N 按 |Δ| 降序。
- [ ] AC6：降级状态：能力探测失败、模型加载失败、整条记录无评分三种输入分别得到「列表视图 + 对应提示」的状态描述，都不产生「看起来像 0 分」的渲染输入。
