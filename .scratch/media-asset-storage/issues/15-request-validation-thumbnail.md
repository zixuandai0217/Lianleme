# 15 — 请求期校验 + 缩略图异步生成

**What to build:** 用户传错东西当场就知道，而不是等几十秒才失败：不支持的格式、超过大小上限、分辨率太低、动图、以及伪装成图片的文件，都在请求阶段被拦下，既不产生资产也不创建注定失败的分析任务。传对的照片则进入正常流程，分析完成后历史列表里出现一张能正常加载的缩略图——不用把几兆的原图拉到手机上下载一遍才能翻历史。缩略图生成是异步的、可重复触发的，失败了也只是降级成占位图，绝不会连累已经算出来的分析结果。

**Blocked by:** 11 DB 驱动执行器、14 媒体资产实体 + 原图上传 + 签名读图

**Status:** ready-for-agent

- [ ] 校验矩阵全部生效：非白名单内容类型返回 415；超过字节上限返回 413；最短边低于下限返回 400；多帧/动图、解码失败、内容类型与实际格式不符返回 400；以上四种情况均不产生资产、不创建分析任务。
- [ ] 通过校验的图片按 EXIF 方向纠正后存盘，且存档字节的 EXIF 已被清除（含地理位置）；元数据中记录宽高、内容类型与字节数。
- [ ] 分析完成后缩略图由执行器异步生成并写入对象存储；历史接口给出的缩略图 URL 可访问，且图片长边等于配置值、内容类型为图片。
- [ ] 缩略图生成失败时：分析结果仍可查询，历史返回空缩略图 URL 与降级标记，并产生一条降级事件（不静默）。
- [ ] 重复触发缩略图生成是幂等的：同一资产不会写出多份对象，目标对象已存在时直接跳过。
