# 07 — 今日接口区分「无计划 / 休息日」

**What to build:** 用户打开首页时，「今天该练什么」必须能分清三种情况：有计划且今天是训练日、有计划且今天是休息日、根本没有可用计划。现在后两种情况在接口层被混成同一个响应，前端只能一律显示「今天留给恢复」，导致刚注册还没生成计划的用户误以为功能坏了，也挡住了训练会话页的空态分支。这个票先把「今日状态」收敛成一个稳定、可判定的三态契约，后面的会话页与首页引导都依赖它。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] AC1 已有充足计划且今天为训练日时，接口返回 200，响应含今日动作清单（动作数量、总组数、预计时长），且状态标记为训练日，不出现休息日标记。
- [ ] AC2 已有计划但今天为休息日时，接口返回 200，状态标记为休息日，含一条恢复提示文案，且不返回动作清单。
- [ ] AC3 用户没有任何可用计划（从未生成、或计划已归档）时，接口返回 200 且状态标记为「无计划」，与休息日可区分；响应中不含动作清单，也不含休息日文案；不得用 404 表达这个状态。
- [ ] AC4 状态取值是稳定枚举（至少三个：训练日 / 休息日 / 无计划），前端仅凭该字段即可分支；既有的「今天是否需要训练」语义继续可用，响应新增字段不破坏已有调用方（旧字段仍存在且语义不再混淆）。
- [ ] AC5 路由层回归测试各覆盖三种状态一条用例，且首页对「无计划」与「休息日」渲染出不同文案（用户可见差异），两条用例均全绿。
