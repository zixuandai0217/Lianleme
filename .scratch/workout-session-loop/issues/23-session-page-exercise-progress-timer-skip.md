# 23 — 会话页（当前动作 / 进度 / 倒计时 / 跳过）

**What to build:** 训练过程拥有一条真正能推进的页面：顶部是整体进度，中间高亮当前动作（组数、次数、建议重量、要领），提示「第 2/4 组」，点「完成一组」后自动进入按该动作组间休息秒数走的倒计时，还能跳过动作并写明原因，全部练完出现收尾打卡入口。页面所有进度都读服务端返回值，不做本地推算，因此刷新或中断回来看到的是同一份状态。

**Blocked by:** 22 训练会话实体 + 推进 / 恢复接口

**Status:** ready-for-agent

- [ ] AC1 进入会话页后可见当前动作名、「组数 × 次数」、组内进度（形如「第 2/4 组」）与整体进度（已练组数 / 总组数），数值与接口返回一致。
- [ ] AC2 点「完成一组」后上述进度文本立即更新，并自动进入休息态、显示以该动作组间休息秒数为起的倒计时；倒计时结束后回到训练态且可继续点完成一组。
- [ ] AC3 跳过动作必须选择原因（未选择不可提交）；提交后该动作显示为已跳过、整体进度不增加，并提示下一个动作。
- [ ] AC4 全部动作处理完（完成或跳过）后出现「收尾并打卡」入口，点击进入打卡与反馈流程；未处理完时不出现该入口。
- [ ] AC5 刷新页面或重新进入后进度与刷新前一致（从服务端恢复），不出现空白页或进度归零。
- [ ] AC6 休息日与无计划两种空态文案不同，且都不显示「开始训练」按钮：休息日给恢复建议，无计划引导去完成体型分析并生成计划。
