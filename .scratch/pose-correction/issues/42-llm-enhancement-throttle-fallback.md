# 42 — 模型增强 + 节流 + 降级

**What to build:** 在规则之上接模型：识别这是深蹲还是硬拉、把几何问题写成人话（西海岸口语风格），并补充规则覆盖不到的综合判断。同时把成本按住：每周期最多一次调用、同一问题 20 秒内不重复念、单会话有调用上限、连续失败熔断；模型不可用时自动退回纯规则，用户不会因为额度或网络失去功能。

**Blocked by:** 41 规则评估 + 骨架高亮；05 LLM 调用日志与脱敏

**Status:** ready-for-agent

- [ ] AC1：模型可用时周期结果含动作类型（来源 `llm`）与口语化反馈文本（中文为主、每句 1–2 个英文词、无医疗诊断口吻），同时规则问题项与评分仍保留。
- [ ] AC2：每周期最多 1 次模型调用（替身计数断言）；同一问题类型 + 同一动作在 20 秒内不重复播报，但评分继续更新。
- [ ] AC3：单会话调用上限：达到上限后本会话转纯规则且只提示一次「深度点评已暂停」，后续周期模型计数不再增长。
- [ ] AC4：连续 3 次调用失败后熔断：后续周期不再调用（计数不再增长），会话汇总能看出本会话已熔断。
- [ ] AC5：降级可观测：超时/限流/输出不可解析时该周期返回规则结果 + 模板文案 + `degraded=true` 与降级原因，响应 200；未熔断时下一周期仍会尝试。
- [ ] AC6：无 Key 且系统回退关闭：全程纯规则、`degraded=true`、零模型调用，响应不含凭据错误也不引导去配置 Key。
