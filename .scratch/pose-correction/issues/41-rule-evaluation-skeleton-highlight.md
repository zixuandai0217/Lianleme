# 41 — 规则评估 + 骨架高亮

**What to build:** 每个动作周期结束时，先由几何规则给出确定性的问题项与 0–10 质量分：膝内扣、躯干前倾过大、左右不对称、下蹲深度不足、节奏异常等，并指出该标红的关节与连线。规则路径不依赖模型，断网或无 Key 都照常工作，用户因此立刻知道「哪里不对、该看哪里」，模型只在此之上做语言改写。

**Blocked by:** 40 姿态会话 + 帧上行 + 周期切分

**Status:** ready-for-agent

- [ ] AC1：明显膝内扣的合成序列返回问题项：类型为膝内扣、严重度至少 `warn`、涉及关节含膝与髋，质量分落在低分段（用边界值断言评分区间）。
- [ ] AC2：评分随问题增加单调不升（同一动作加入更多严重问题后分数不高于原值），且始终限定在 0–10 内。
- [ ] AC3：视角影响判断：同一段序列在 `front` 与 `side` 声明下返回的问题集合不同（正面看对称性、侧面看前倾与深度），接口按视角选用不同阈值。
- [ ] AC4：高亮集合与问题项一致：每个问题项给出应高亮的关节或连线，严重（红）与提示（橙）可由响应字段区分。
- [ ] AC5：规则路径零模型调用：整段流程在模型替身计数为 0 的前提下产出问题项、评分与高亮；无 Key 时响应不含凭据错误。
- [ ] AC6：反馈克制：每个周期只给一句主提示（可带一句补充），先讲最严重的那一个问题，不罗列全部问题。
