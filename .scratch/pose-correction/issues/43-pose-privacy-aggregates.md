# 43 — 隐私边界与聚合摘要

**What to build:** 姿态关键点是生物特征，这张票把边界钉死并给用户可带走的价值：关键点只在会话内内存处理、周期结束即丢弃、不落盘不进模型记忆不写日志；训练结束只保留数值聚合（周期数、平均质量分、问题类型直方图），用户可清除。这份聚合再以只读摘要形式交给伤病风险评估——只给数值，不给坐标。

**Blocked by:** 40 姿态会话 + 帧上行 + 周期切分

**Status:** ready-for-agent

- [ ] AC1：姿态相关接口的响应都不含关键点坐标数组（对会话创建、帧批、结果、结束四个响应断言），只有评分、问题项、高亮关节引用与聚合数值。
- [ ] AC2：周期处理完成后不保留原始帧：会话结束后无法通过任何接口取回坐标级数据（结束后读取返回空态或 4xx）。
- [ ] AC3：结束会话返回聚合摘要：周期数、平均质量分、问题类型直方图、不可评估周期占比；摘要不含「某天第几组出了什么问题」这类可还原到动作实例的明细。
- [ ] AC4：结构化日志只含会话短标识、周期序号、耗时、错误分类与规则命中类型，不含坐标或角度数值序列（在测试捕获的日志记录里断言无坐标字段）。
- [ ] AC5：用户可删除自己的聚合记录，删除后读取为空态且不能通过其它接口重算；他人聚合不可读（403）。
- [ ] AC6：供伤病风险评估的摘要只含数值聚合（平均分、top-N 问题类型、覆盖训练次数、不可评估占比），可被下游只读获取且不含任何关键点或单次动作明细。
