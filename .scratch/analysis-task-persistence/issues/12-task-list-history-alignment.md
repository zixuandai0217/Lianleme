# 12 — 任务列表与历史对齐

**What to build:** 用户打开「我的分析」，看得到最近这些分析任务的真实状态：正在跑的、失败了的、过期作废的都各就各位，而不是只有成功的那几条。排障时也能反过来查：某个用户的失败任务排在最上面，一眼看出错误码是什么时候出现的。同时把「任务」与「历史」分成两层讲清楚——任务列表是执行记录（会过期清理），历史列表是长期资产（只在成功时产生），一条历史能反查到自己来自哪次任务。

**Blocked by:** 10 任务轮询改读数据库

**Status:** ready-for-agent

- [ ] `GET /api/vision/tasks` 返回当前用户的任务摘要：任务标识、状态、错误码、创建与更新时间、对应历史记录标识；按创建时间倒序。
- [ ] 支持按状态过滤（五态任选其一）与游标分页：不传游标取第一页；传非法游标或越界分页参数返回 422；连续翻页不重复、不丢项。
- [ ] 列表只含本人任务：任何请求参数或标识探测都取不到他人任务（返回 403 或空列表，语义固定且一致）。
- [ ] 历史接口只返回已完成分析对应的记录，且每条带对应任务标识；失败与过期任务出现在任务列表但不出现在历史列表。
- [ ] 任务列表只返回摘要级字段且不含图片内容或结果明细；历史接口既有字段保持向后兼容，新增字段不影响旧前端解析。
