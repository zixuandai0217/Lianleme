# 25 — 两路 LLM 分析器 + 降级

**What to build:** 伤病风险与体重/体脂趋势这两维需要模型做深度判断，本票把它们接上并给出完整降级路径：模型可用时输出结构化评分与理由；超时、输出不可解析、或用户没有可用 Key 时自动降级为规则近似加模板文案并明确标记，调整照常完成。用户不会因为没配 Key 而看到报错，也不会因为模型抖动丢掉这次评估。送给模型的输入只含聚合摘要，不含身份与逐日原始明细。

**Blocked by:** 24 Analyzer 抽象 + 三路规则 + Merge Node；05 LLM 调用日志与脱敏

**Status:** ready-for-agent

- [ ] AC1：模型可用时两维返回结构化结果（评分 0–10、理由、建议、来源 `llm`），调用温度固定为 0；用固定替身输出可断言两维评分与理由进入合并结果。
- [ ] AC2：超时、限流/鉴权失败、输出不可解析三种失败各返回降级结果：该维 `degraded=true`、有规则近似评分与模板理由，其余维度与决策方向不受影响（响应 200）。
- [ ] AC3：无用户 Key 且系统回退关闭：评估返回 200、两维均降级、响应中不出现凭据错误码或「请配置 API Key」文案，模型替身计数为 0。
- [ ] AC4：一次评估的模型调用不超过 2 次（替身计数断言）；两维在合并中与其他维度同权，不因实现方式不同加权。
- [ ] AC5：入参最小化：替身记录到的请求只含聚合摘要（均值、趋势方向、计数、训练天数），不含用户标识、邮箱、照片或逐日原始数值序列。
- [ ] AC6：降级可观测：合并结果带降级维度清单与降级原因分类，08 的结论与 26 的详情都能读到「本次未做深度分析」。
