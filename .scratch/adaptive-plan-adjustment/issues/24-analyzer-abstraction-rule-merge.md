# 24 — Analyzer 抽象 + 三路规则 + Merge Node

**What to build:** 一次调整从「只看完成率」升级为五个维度并行体检：完成率、疲劳度、伤病风险、睡眠、体重/体脂趋势各出一份评分、理由与建议，再由 Merge Node 汇成整体健康分、风险信号与最该听的三条理由，据此给出调整方向。本票只做统一 Analyzer 形状、三路确定性规则（完成率/疲劳/睡眠）与合并，两路模型分析留到下一票，因此交付后即便没有任何模型可用，五维小结与方向也能产出（两路以「未评估」占位）。

本票同时把五维明细与合并分**追加进 08 建立的调整结论记录**（扩展该记录，不新建并行存储），供 26 的 detail 直接读取（Lead 裁决）。

**Blocked by:** 06 迁移基线对齐与一致性测试；08 调整结论落盘最小契约

**Status:** ready-for-agent

- [ ] AC1：一次评估产出五个维度条目，每条含名称、0–10 健康评分、理由、建议、来源（`rule | llm`）与降级标记；三路规则维评分符合 ADR-0003 阈值（完成率 ≥0.85→9、0.7–0.85→7、<0.7→5；疲劳 1–2→9–10、3→7、4–5→3–5；睡眠 ≥7h 且质量 ≥4→9、6–7h→7、<6h→5），用固定输入可逐条断言。
- [ ] AC2：Merge Node 输出整体健康分（参与维度的等权平均，剔除缺省维度并列出清单）、风险信号列表、最多 3 条顶层理由；据此得出的方向落为 `increase | decrease | keep`，且能被 08 的结论读出来。
- [ ] AC3：缺数据走缺省而非报错：无疲劳/睡眠数据时按疲劳 3、睡眠 3 分 / 7 小时参与，并标注「数据为缺省」；响应仍为 200，不出现 4xx/5xx。
- [ ] AC4：维度失败隔离：人为让其中一维的输入非法时，该维降级、其余四维与方向照常产出，整体响应 200。
- [ ] AC5：本票零模型调用：整趟评估在模型替身计数为 0 的前提下完成五维小结与方向（用替身计数断言）。
