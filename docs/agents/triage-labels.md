# Triage label vocabulary

标签到字符串的映射（用于本地 markdown issue tracker 的 frontmatter）：

| 角色 | 标签字符串 |
|------|-----------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Delivered | `delivered` |
| Won't fix | `wontfix` |

这些标签会出现在 `.scratch/*/issue.md` 文件的 frontmatter `status` 字段中。
